## Règles

- Aucune donnée réelle client, aucun token ni clé API.
- Les visuels proviennent de `design/` et les vidéos de `video/`.
- Toute affirmation chiffrée (« 10 000+ utilisateurs ») doit être vérifiée avant publication — voir la règle copy de `skills/react-ui-djassa/SKILL.md`.
- Copy en français, ton sobre, pas d'hype ni d'émoji.
